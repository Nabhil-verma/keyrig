# Glossary

Use one word for one meaning. Add a word here before you use a new word in the UI.

| Word | Meaning | Do not use |
|---|---|---|
| key | A provider credential. | token, secret, API key |
| key label | The user name for a key. | key name, alias |
| provider | A company or a local server that serves models. | vendor, backend |
| model | A named model that a provider serves. | engine |
| profile | A saved group of provider, model, key label and options. | preset, config |
| request | One call from keyrig to a provider. | query, completion |
| response | The answer from the provider. | reply, output |
| usage | The token counts for one request. | metrics |
| cost | The estimated money for one request. | price |
| arena | One prompt sent to many models at the same time. | race, compare |
| artifact | A file or a preview that keyrig shows next to the chat. | output, result |
| checkpoint | A saved copy of the workspace before a change. | snapshot, backup |
| tool | A function that the model can call. | action |
| approval | A user decision that lets one tool call run. | permission |
