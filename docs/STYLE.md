# Writing style

keyrig uses ASD-STE100 (Simplified Technical English). The full dictionary is a licensed document.
This file holds the rules that apply to this repository. See spec section 0.1.

## Rules

1. Write short sentences. Use 20 words or fewer for an instruction. Use 25 words or fewer for a description.
2. Write one instruction in each sentence.
3. Use the active voice. Write "The app saves the key". Do not write "The key is saved".
4. Use the simple present tense for facts. Use the imperative for steps.
5. Use one word for one meaning. Use the same word for the same thing in all places.
6. Use the article ("the", "a") in front of each noun. Do not omit the article.
7. Do not use more than three nouns in a row.
8. Do not use slang, idioms or contractions.
9. Use a list for steps. Use a numbered list when the order is important.
10. Put a warning before the step it applies to. Start the warning with "WARNING" or "CAUTION".
11. Keep each paragraph to six sentences or fewer.
12. Technical names (API, MCP, OAuth, token) are allowed. Use them in the same way each time.
13. Prefer these words:

| Use | Do not use |
|---|---|
| start | initiate |
| use | utilize |
| make sure | ensure |
| stop | terminate |
| show | display |
| change | modify |
